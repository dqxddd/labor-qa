# labor-qa
基于 RAG 的劳动法规问答系统：双路检索（Chroma 向量 + 关键词兜底）、库外问题硬拒答、业务工具算法定期限、引用溯源、对话记忆/A RAG-based labor-law Q&amp;A system: dual-path retrieval (Chroma vector + keyword fallback), a hard refusal gate for out-of-knowledge questions, tool calling for statutory deadlines, citation tracing, and conversation memory. FastAPI + SQLAlchemy + Streamlit.
